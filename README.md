# Supply Inventory (Python/Flask)

Blue-themed Supply Inventory system starter app with:
- User authentication and role-based access (Admin, Inventory Staff, Viewer)
- Dashboard cards and recent transactions
- Supply management with search/filter and add form
- Category, supplier, stock transactions, and audit models

## Run
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Then open `/init` once to create tables and default admin:
- username: `admin`
- password: `admin123`
